| Componente      | Responsabilidade                            |
| --------------- | ------------------------------------------- |
| Header          | Nome da aplicação                           |
| CollectorStatus | Última atualização e status do coletor      |
| SummaryCard     | Exibir um indicador (bateria, falhas, etc.) |
| FilterBar       | Filtros da tela                             |
| RobotTable      | Exibir qualquer lista de robôs              |
| Dashboard       | Organizar todos os componentes              |
